# Fermento Cultural — Site

Site institucional da Fermento Cultural (www.fermentocultural.com.br), construído com [Next.js](https://nextjs.org).

O conteúdo editável fica em `src/content/*.ts`. Push na branch `main` dispara o deploy automático via GitHub Actions.

## Desenvolvimento local

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.
